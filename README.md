# 全臺A1類（死亡）道路交通事故資料長期趨勢分析

延續「臺灣雨量核心儀表板」中已使用過的交通事故資料維度，改以警政署公開於data.gov.tw的「A1類（造成人員當場或24小時內死亡）道路交通事故資料」為對象，涵蓋2019～2022年共4個年度，做時段／天候／道路型態的長期趨勢與多因子交叉分析，並加入地圖視覺化。是「政府開放資料應用案例」系列的延伸主題。

線上報告頁面：開啟本repo的GitHub Pages連結即可看到（`index.html`）。

## 資料集

- 來源：警政署[「XX年傷亡道路交通事故資料」](https://data.gov.tw/)開放資料集，data.gov.tw。
- 範圍：按年度分別下載A1類（死亡）事故資料，取得2019～2022年（民國108～111年）共4個年度。
- 資料集本身不包含在這個repo裡，需要自行從data.gov.tw下載對應年度的A1交通事故CSV。

## 專案流程與腳本

腳本依執行順序編號，直接放在repo根目錄，執行前請把對應腳本跟下載到的各年度「OO年度A1交通事故資料.csv」放在同一個資料夾：

1. `01_data_exploration.py` — 確認4個年度資料能否正常合併讀取、欄位、去重複邏輯（同一事故因多當事者產生的重複列問題），並檢查天候、光線、道路型態、經緯度等欄位分布。
2. `02_eda_charts.py` — 年度趨勢、24小時時段分布、天候別比較、天候×事故位置交叉比較、光線狀況比較，共5張圖表。
3. `03_advanced_analysis.py` — 地圖視覺化（事故地點密度熱點圖）、道路型態分析、道路型態×日夜交叉、天候×光線交叉，共4張圖表。

## 資料品質：去重複邏輯

原始資料以「當事者」為單位儲存，同一事故若有多個當事者（例如機車＋汽車），會產生多列重複的事故層級欄位（天候、道路型態、經緯度等）。合併4個年度共18,299列原始資料後，以（發生年度、發生月份、發生日期、發生時間、發生地點、經度、緯度）7個欄位組成唯一鍵去重複，得到7,235件不重複事故，平均每件事故約2.53筆當事者列。另外原始CSV尾端附有「事故類別：A1類」等說明列，已用「發生年度必須是純數字」的檢查過濾掉。

## 分析結果

### 年度趨勢與時段分析

2019～2022四年事故件數幾乎持平（1,814／1,806／1,806／1,809件），沒有明顯上升或下降趨勢。時段分布上，事故最集中於早上7點（450件），整體呈現「上下班尖峰時段」偏高的型態，凌晨3點最低（140件）。

### 天候與事故位置

晴天事故佔絕大多數（5,765件，79.7%），陰天767件、雨天677件。比較「同一天候下路口事故的佔比」後發現：雨天事故發生在交叉路口的比例（37.4%）反而低於晴天（44.6%），推測雨天風險因子可能更多來自路段本身。

### 光線與道路型態

日間自然光佔60.2%，夜間有照明31.9%，夜間無照明僅佔全部夜間事故的10.0%。道路型態上「單路部分」佔55.3%、「交岔路」佔44.5%；交叉比較後單路部分的夜間事故佔比（39.7%）明顯高於交岔路（30.3%）與整體平均（35.5%）。

### 地圖視覺化與多因子交叉

事故地點密度熱點圖清楚浮現臺灣本島（含澎湖、金門、馬祖）的輪廓，熱點集中在西部沿海都會區帶。天候×光線交叉分析顯示：雨天事故中日間光線僅佔43%，明顯低於晴天的64%，指向「雨天的風險因子主要來自光線／視線條件」的推論。

## 限制

本分析僅涵蓋A1類（造成人員當場或24小時內死亡）事故，未納入樣本數遠大於A1類的A2類（受傷或24小時後死亡）事故，結論僅代表最嚴重事故的型態，不能直接推論到全部交通事故的整體風險分布。部分交叉分析細分類別樣本數偏少（如強風、風沙天候僅個位數件），已在各分析中排除避免統計誤導。
